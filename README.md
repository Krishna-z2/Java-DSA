## Day 6 — Reverse a Number

The **Reverse a Number** problem was a pretty amazing question that helps me to explains the Mathematical Understanding.
Initially, I Struggled with Updating variables inside the loop and building the reversed number correctly. After trying  2 or 3 Times and Taking Hints from AI , I understood:

- How `% 10` extracts the last digit of a number.
- How `/ 10` removes the last digit.
- How to build the reversed number using `reversed = reversed * 10 + remainder`.

**Key Takeaway:** This problem helped me improve my logical thinking, debugging skills, and understanding of `while` loops. Solving it step by step was more valuable than Simply Memorizing the Solution.



## Day 9 – Hollow Pyramid Pattern 

Today I practiced the **Hollow Pyramid Pattern**, and it was a so much pain.

I understood how to print normal pyramid patterns, but making the inside hollow was a different challenge.

The interesting part was figuring out how the spaces and stars change in every row. I learned that instead of thinking about the whole pattern at once, it's easier to break it into smaller parts.

**What I learned:**
- How to manage leading spaces using `n - i`.
- How the number of positions changes using `2 * i - 1`.
- How to use conditions to print stars only at the boundaries.
- How small mistakes in loop conditions or `print()` and `println()` can change the entire output.

This question really helped me understand nested loops and conditions better.

**Today's takeaway:** Don't memorize patterns. Understand how each row is formed, and the logic becomes much easier. 🚀
